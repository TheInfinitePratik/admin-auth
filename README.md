# 🔐 Admin Auth - Login UI

A modern and responsive login interface built using Next.js and Tailwind CSS.

## 🚀 Live Demo

https://admin-auth-six.vercel.app

## 📌 Features

* Clean and modern login design
* Responsive layout (mobile + desktop)
* Email & password input fields with icons
* Social login buttons (UI only)
* Smooth gradient styling

## 🛠️ Tech Stack

* Next.js
* React
* Tailwind CSS
* Font Awesome

## 📂 Project Structure

* `/src/app` → Pages and routing
* `/components` → Reusable UI components

## ⚙️ Installation & Setup

Clone the repository:
git clone https://github.com/TheInfinitePratik/admin-auth.git

Navigate to project folder:
cd admin-auth

Install dependencies:
npm install

Run the development server:
npm run dev
